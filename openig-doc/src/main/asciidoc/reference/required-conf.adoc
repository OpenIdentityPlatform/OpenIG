[#required-conf]
== Required Configuration

OpenIG loads the gateway and administration configuration separately. Each configuration has its own heap.
[#GatewayHttpApplication]
=== GatewayHttpApplication — configure OpenIG

[#d210e2027]
==== Description
The GatewayHttpApplication is the entry point for all incoming requests. It is responsible for initializing a heap of objects, described in xref:#heap-objects[Heap Objects(5)], and providing the main Handler that receives all the incoming requests. The configuration is loaded from a JSON-encoded configuration file, expected by default at `$HOME/.openig/config/config.json`.
The gateway supplies xref:#d210e2241[default heap objects] for outbound HTTP, buffering, scheduling, and decoration. Routes can use them through their parent heap.

[#d210e2093]
==== Usage

[source, javascript]
----
{
  "handler": Handler reference or inline Handler declaration,
  "heap": [ configuration object, ... ],
  "temporaryStorage": TemporaryStorage reference or inline declaration,
  "properties": { name: value, ... },
  "globalDecorators": { decoratorName: decorationValue, ... }
}
----

[#d210e2099]
==== Properties
--

`"handler"`: __Handler reference, required__::
Dispatch all requests to this handler.

+
Provide either the name of a Handler object defined in the heap, or an inline Handler configuration object.

+
See also xref:handlers-conf.adoc#handlers-conf[Handlers].

`"heap"`: __array of configuration objects, optional__::
The heap object configuration, described in xref:#heap-objects[Heap Objects(5)].

+
You can omit an empty array. If you only have one object in the heap, you can inline it as the handler value.

`"temporaryStorage"`: __TemporaryStorage reference, optional__::
Cache content during processing based on this TemporaryStorage configuration.

+
Provide either the name of a TemporaryStorage object defined in the heap, or an inline TemporaryStorage configuration object.

+
Default: use the heap object named TemporaryStorage. Otherwise use an internally-created TemporaryStorage object that is named TemporaryStorage and that uses default settings for a TemporaryStorage object.

+
See also xref:misc-conf.adoc#TemporaryStorage[TemporaryStorage(5)].

anchor:gateway-properties[]
`"properties"`: __object, optional__::
Named values for configuration expressions in this heap and its child heaps. Defaults to an empty object. OpenIG evaluates entries in declaration order. An entry can refer to parent heap properties or earlier entries. Child heap properties take precedence in that heap. Use the same field in a xref:handlers-conf.adoc#Route[route] to define route-local properties.

+
A property value consisting of an object with only a `$location` field loads JSON from the specified URL, such as a local `file:` URL. See xref:expressions-conf.adoc#Expressions[Expressions] for binding availability and evaluation.

`"globalDecorators"`: __object, optional__::
Apply decorations across the heap. See xref:decorators-conf.adoc#decorators-conf[Decorators] for the declaration format and order of application.

--

[#d210e2165]
==== Javadoc
link:{apidocs-url}/org/forgerock/openig/http/GatewayHttpApplication.html[org.forgerock.openig.http.GatewayHttpApplication, window=\_blank]

[#admin-json]
=== admin.json — configure the administration application

The servlet loads `admin.json` from the OpenIG configuration directory, which defaults to `$HOME/.openig/config`. Put administration settings in this file. `config.json` configures the gateway request handler and its separate heap.

[source,json]
----
{
    "mode": "PRODUCTION",
    "prefix": "openig",
    "heap": []
}
----

`"mode"` (string or configuration expression, optional)::
`EVALUATION` enables Studio and leaves the administration endpoints accessible to remote clients by default. `PRODUCTION` disables Studio and restricts the endpoints to clients connecting from a loopback address when no custom `ApiProtectionFilter` is configured. The default is `EVALUATION`.

`"prefix"` (string, optional)::
The path prefix for administration routes relative to the servlet context, without a leading slash. The default `openig` exposes the administration API below `/openig/api` in a root deployment.

`"heap"` (array of configuration objects, optional)::
The administration application's xref:#heap-objects[heap]. To customize protection, define a filter named `ApiProtectionFilter` in this heap. OpenIG uses that filter in either mode, including in place of the loopback restriction in `PRODUCTION`.

`"temporaryStorage"` (heap reference or inline declaration, optional)::
Buffer storage for the administration application. The default is the `TemporaryStorage` heap object.

`"properties"` (object, optional)::
Named configuration xref:#gateway-properties[properties] for expressions in the administration heap. OpenIG evaluates `mode` before loading this heap.

`"globalDecorators"` (object, optional)::
A map of xref:decorators-conf.adoc#decorators-conf[decorations] for eligible objects resolved in the administration heap.

link:{apidocs-url}/org/forgerock/openig/http/AdminHttpApplication.html[org.forgerock.openig.http.AdminHttpApplication, window=\_blank]

[#heap-objects]
=== Heap Objects — configure and initialize objects, with dependency injection

[#d210e2184]
==== Description
A heap is a collection of associated objects, initialized from declarative configuration artifacts. All configurable objects in OpenIG are heap objects. Heap objects are created and initialized by associated heaplets, which retrieve any objects an object depends on from the heap. The heap configuration is included as an object in the GatewayHttpApplication configuration, as described in xref:#GatewayHttpApplication[GatewayHttpApplication(5)].

[#d210e2196]
==== Usage

[source, javascript]
----
[
    {
        "name": string,
        "type": string,
        "config": {
            object-specific configuration
        }
    },
    ...
]
----

[#d210e2205]
==== Properties
--

`"name"`: __string, required except for inline objects__::
The unique name to give the heap object in the heap. This name is used to resolve the heap object, for example, when another heap object names a heap object dependency.

`"type"`: __string, required__::
A xref:#heap-types[heap type alias] or fully qualified class name.

`"config"`: __object, optional__::
The configuration specific to the heap object. OpenIG supplies an empty object when you omit this field. Provide every field required by the declared type for its intended operation.

--

[#d210e2241]
==== Automatically Created Objects
--
The gateway heap provides the following defaults. Define a heap object with the same name to override a default. Routes inherit these objects.

`TemporaryStorage`::
Default buffer storage using the settings in xref:misc-conf.adoc#TemporaryStorage[TemporaryStorage].

`ClientHandler`::
Default xref:handlers-conf.adoc#ClientHandler[ClientHandler] for outbound HTTP requests.

`ForgeRockClientHandler`::
A xref:handlers-conf.adoc#Chain[Chain] that adds the Common Audit transaction ID to outbound requests using `TransactionIdOutboundFilter`, then calls `ClientHandler`.

`ScheduledExecutorService`::
Default xref:misc-conf.adoc#ScheduledExecutorService[ScheduledExecutorService] shared by objects that use it for scheduled work.

`baseURI`, `capture`, `timer`::
Built-in xref:decorators-conf.adoc#decorators-conf[decorators] that change the request URI, capture messages, and record execution time, respectively. The administration heap supplies `capture` and `timer`.

`Session`::
Define a session manager such as xref:misc-conf.adoc#JwtSession[JwtSession] under this name to select it for the gateway. The default session for HTTP requests is the servlet container's HTTP session.

--

For Java extensions, the gateway supplies `Environment`, `TimeService`, `Ticker`, `EndpointRegistry`, and `RunMode` through the keys defined in link:{apidocs-url}/org/forgerock/openig/heap/Keys.html[`Keys`]. Routes have an endpoint registry scoped to their own objects.

[#d210e2293]
==== Implicit Properties
--
A heap object can override the default buffer storage with this implicit property:

`"temporaryStorage"`: __heap reference or inline declaration__::
Specifies the xref:misc-conf.adoc#TemporaryStorage[TemporaryStorage] object for eligible heap objects that use temporary buffers.

+
Default: `TemporaryStorage`.

--

[#configuration]
=== Configuration Settings — configure objects

[#d210e2341]
==== Description
The reference for each property specifies whether it accepts an expression and when OpenIG evaluates it. Configuration expressions are evaluated when the object is created, such as at startup or when a route is reloaded. They can use heap properties, system properties, and environment variables. Request-time expressions can read the current request or response where the object supplies it.

If a configuration expression yields `null`, the property is treated as absent by heaplets that evaluate configuration before applying defaults. A required property then causes configuration to fail. An optional property uses its default where one is defined.

This example reads the JVM system property `requestsPerSecond` as an integer and the environment variable `ENABLE_MONITORING` as a boolean.

[source, json]
----
{
  "handler": {
    "type": "Chain",
    "config": {
      "filters": [
        {
          "type": "ThrottlingFilter",
          "config": {
            "requestGroupingPolicy": "${request.headers['UserId'][0]}",
            "rate": {
              "numberOfRequests": "${integer(system['requestsPerSecond'])}",
              "duration": "10 seconds"
            }
          }
        }
      ],
      "handler": "ClientHandler"
    }
  },
  "monitor" : "${bool(env['ENABLE_MONITORING'])}",
  "condition": "${matches(request.uri.path, '^/throttle-simple')}"
}
----
If `"requestsPerSecond"=150` and `"ENABLE_MONITORING"=false`, after the expressions are evaluated OpenIG views the example route as follows:

[source, json]
----
{
  "handler": {
    "type": "Chain",
    "config": {
      "filters": [
        {
          "type": "ThrottlingFilter",
          "config": {
            "requestGroupingPolicy": "${request.headers['UserId'][0]}",
            "rate": {
              "numberOfRequests": 150,
              "duration": "10 seconds"
            }
          }
        }
      ],
      "handler": "ClientHandler"
    }
  },
  "monitor" : false,
  "condition": "${matches(request.uri.path, '^/throttle-simple')}"
}
----
For information about expressions, see xref:expressions-conf.adoc#Expressions[Expressions(5)].
