[#Client]
=== Client — HTTP client context information

[#d210e17222]
==== Description
Provides information about the client sending the request.

This is one of the contexts described in xref:#Contexts[Contexts(5)].

[#d210e17236]
==== Properties
--

`"certificates"`: collection::
The certificates presented by the client. The servlet entry point supplies X.509 certificates.

+
If the client does not present any certificates, OpenIG returns an empty list.

+
This is never `null`.

`"external"`: boolean::
True if the client connection is external.

`"secure"`: boolean::
True if the client connection is secure.

`"localAddress"`: string::
The IP address of the interface that received the request

`"localPort"`: number::
The port of the interface that received the request

`"remoteAddress"`: string::
The IP address of the client (or the last proxy) that sent the request

`"remotePort"`: number::
The source port of the client (or the last proxy) that sent the request

`"remoteUser"`: string::
The login of the user making the request, or `null` if unknown

+
This is likely to be `null` unless you have deployed OpenIG with a non-default deployment descriptor that secures the OpenIG web application.

`"userAgent"`: string::
The value of the User-Agent HTTP header in the request if any, otherwise `null`

[#Contexts]
=== Contexts — HTTP request contexts

[#d210e17350]
==== Description
`context` is the current context object. The `contexts` map looks up objects by context name. OpenIG builds the map by walking from the current context toward the root. If a name occurs more than once, the map uses the occurrence nearest the current context. The other occurrences remain accessible through the `parent` chain.
--
All context objects have the following properties:

`"contextName"`: string::
Name of the context.

`"id"`: string::
Read-only string uniquely identifying the context object.

`"rootContext"`: boolean::
True if the context object is a RootContext (has no parent).

`"parent"`: Context object::
Parent of this context object.

--

[#d210e17401]
==== Properties
--
The contexts below are available when the request source or a filter adds them. The standard servlet entry point supplies `root`, `session`, `router`, `requestAudit`, `attributes`, and `client`. Requests from message brokers begin with `root` and `attributes`.

`"attributes"`: AttributesContext object::
Arbitrary state information.

+
OpenIG can use this to inject arbitrary state information into the context.

+
See also xref:#Attributes[Attributes(5)].

`"client"`: ClientContext object::
Information about the client making the request.

+
See also xref:#Client[Client(5)].

`"router"`: UriRouterContext object::
Routing information associated with the request.

+
See also xref:#UriRouterContext[UriRouterContext(5)].

`"session"`: SessionContext object::
Session context associated with the remote client.

+
See also xref:#Session[Session(5)].

`"root"`: RootContext object::
Root of the context chain. Its `parent` is `null`.

`"requestAudit"`: RequestAuditContext object::
`requestReceivedTime` is the time the request reached the framework, in milliseconds since the Unix epoch.

`"oauth2"`: OAuth2Context object::
The xref:filters-conf.adoc#OAuth2ResourceServerFilter[OAuth2ResourceServerFilter] provides `accessToken` for a validated request. See xref:#AccessTokenInfo[AccessTokenInfo] for token properties.

`"ssoToken"`: SsoTokenContext object::
The xref:filters-conf.adoc#SingleSignOnFilter[SingleSignOnFilter] provides session information in the `info` map and the SSO token string in `value`.

`"policyDecision"`: PolicyDecisionContext object::
The xref:filters-conf.adoc#PolicyEnforcementFilter[PolicyEnforcementFilter] supplies the policy decision. The `attributes` and `advices` properties are maps of string keys to lists of strings. `jsonAttributes` and `jsonAdvices` expose those values as `JsonValue` objects, preserving the JSON structure.

`"sts"`: StsContext object::
The xref:filters-conf.adoc#TokenTransformationFilter[TokenTransformationFilter] exposes the token issued by the STS in `issuedToken`. See the filter for cases that produce an empty string.

`"jwtBuilder"`: JwtBuilderContext object::
The xref:filters-conf.adoc#JwtBuilderFilter[JwtBuilderFilter] exposes the compact JWT string as `value`, the claims map as `claims`, and its `JsonValue` representation as `claimsAsJsonValue`.

--

[#AccessTokenInfo]
=== AccessTokenInfo — validated OAuth 2.0 access token

Access the token as `contexts.oauth2.accessToken` after validation by an xref:filters-conf.adoc#OAuth2ResourceServerFilter[OAuth2ResourceServerFilter].

`"info"`: map::
The token information supplied by the access token resolver, as a map.

`"token"`: string::
The access token identifier.

[#Cookie]
=== Cookie — incoming HTTP cookie

`request.cookies` maps each name to a list of these objects. Optional cookie attributes can be absent.

[cols="1,3",options="header"]
|===
| Property | Value

| `name` | Cookie name.
| `value` | Cookie value.
| `domain` | Domain to which the cookie applies.
| `path` | Path to which the cookie applies.
| `expires` | Expiration date as a Java `Date`.
| `maxAge` | Maximum age in seconds.
| `sameSite` | SameSite setting.
| `comment` | Description of the cookie's purpose.
| `commentURL` | URL describing the cookie's purpose.
| `discard` | Whether the user agent should discard the cookie when it terminates.
| `port` | List of allowed port numbers.
| `version` | Cookie protocol version.
|===

[#Entity]
=== Entity — HTTP message body

Both `request.entity` and `response.entity` expose the following properties.

`"bytes"`: byte array::
A copy of the decoded content.

`"json"`: object::
The content parsed as JSON. For example, `+${request.entity.json['name']}+` reads a field from a JSON object. An EL evaluation error, including malformed JSON, yields `null`.

`"string"`: string::
The decoded content as text.

`"decodedContentEmpty"`, `"rawContentEmpty"`: boolean::
`true` when the entity is empty. Both properties use the same check in the current HTTP framework and return `true` if the check encounters an I/O error.

`"rawContentInputStream"`: InputStream::
The current stream owned by the entity. Reading it advances the entity's stream position. Use `bytes`, `json`, or `string` to inspect the body without advancing that position. Closing the entity also closes its stream.

[#Request]
=== Request — HTTP request

[#d210e17477]
==== Description
An HTTP request message.

[#d210e17485]
==== Properties
--

`"method"`: __string__::
The method to be performed on the resource. Example: `"GET"`.

`"uri"`: __object__::
The fully-qualified URI of the resource being accessed. Example: `"http://www.example.com/resource.txt"`.

+
See also xref:#URI[URI(5)].

`"version"`: __string__::
Protocol version. Example: `"HTTP/1.1"`.

`"headers"`: __object__::
Exposes message header fields as name-value pairs, where name is header name and value is an array of header values.

`"cookies"`: __map__::
Maps each cookie name to a list of xref:#Cookie[Cookie] objects. For example, `+${request.cookies['name'][0].value}+` reads the value of the first cookie named `name`.

`"form"`: __object__::
Exposes query parameters and/or `application/x-www-form-urlencoded` entity as name-value pairs, where name is the field name and value is an array of string values.

`"entity"`: __Entity object__::
The message body. See xref:#Entity[Entity].

--

[#Status]
=== Status — HTTP response status

[#d210e17726]
==== Description
Represents an HTTP response status. For details, see link:https://tools.ietf.org/html/rfc7231#section-6.1[RFC 7231: HTTP/1.1 Semantics and Content, Section 6.1. Overview of Status Codes, window=\_blank].

[#d210e17741]
==== Properties
--

`"code"`: __integer__::
Three-digit integer reflecting the HTTP status code.

`"family"`: __enum__::
Family Enum value representing the class of response that corresponds to the code:
+
[open]
====

`Family.INFORMATIONAL`::
Status code reflects a provisional, informational response: 1xx.

`Family.SUCCESSFUL`::
The server received, understood, accepted and processed the request successfully. Status code: 2xx.

`Family.REDIRECTION`::
Status code indicates that the client must take additional action to complete the request: 3xx.

`Family.CLIENT_ERROR`::
Status code reflects a client error: 4xx.

`Family.SERVER_ERROR`::
Status code indicates a server-side error: 5xx.

`Family.UNKNOWN`::
Status code does not belong to one of the known families: 600+.

====

`"reasonPhrase"`: __string__::
The human-readable reason-phrase corresponding to the status code.

+
For details, see link:https://tools.ietf.org/html/rfc7231#section-6.1[RFC 7231: HTTP/1.1 Semantics and Content, Section 6.1. Overview of Status Codes, window=\_blank].

`"clientError"`: __boolean__::
True for `Family.CLIENT_ERROR`.

`"informational"`: __boolean__::
True for `Family.INFORMATIONAL`.

`"redirection"`: __boolean__::
True for `Family.REDIRECTION`.

`"serverError"`: __boolean__::
True for `Family.SERVER_ERROR`.

`"successful"`: __boolean__::
True for `Family.SUCCESSFUL`.

--

[#URI]
=== URI — Uniform Resource Identifier

[#d210e17895]
==== Description
Represents a Uniform Resource Identifier (URI) reference.

[#d210e17905]
==== Properties
--

`"scheme"`: __string__::
The scheme component of the URI, or `null` if the scheme is undefined.

`"authority"`: __string__::
The decoded authority component of the URI, or `null` if the authority is undefined.

+
Use "rawAuthority" to access the raw (encoded) component.

`"userInfo"`: __string__::
The decoded user-information component of the URI, or `null` if the user information is undefined.

+
Use "rawUserInfo" to access the raw (encoded) component.

`"host"`: __string__::
The host component of the URI, or `null` if the host is undefined.

`"port"`: __number__::
The explicit port number, or `-1` if the URI has no port.

`"path"`: __string__::
The decoded path component of the URI, or `null` if the path is undefined.

+
Use `rawPath` to access the raw (encoded) component.

`"pathElements"`: __list of strings__::
An immutable list of the path segments.

`"query"`: __string__::
The decoded query component of the URI, or `null` if the query is undefined.

+
Use "rawQuery" to access the raw (encoded) component.

`"fragment"`: __string__::
The decoded fragment component of the URI, or `null` if the fragment is undefined.

+
Use "rawFragment" to access the raw (encoded) component.

--

[#UriRouterContext]
=== Router — HTTP request routing context information

[#d210e18043]
==== Description
Provides context information related to HTTP request routing.

This is one of the contexts described in xref:#Contexts[Contexts(5)].

[#d210e18057]
==== Properties
--

`"baseUri"`: string::
The portion of the request URI matched so far, including matches in parent router contexts. May be empty.

`"matchedUri"`: string::
The portion of the request URI that matched the URI template.

`"originalUri"`: URI::
The original target link:https://docs.oracle.com/en/java/javase/11/docs/api/java.base/java/net/URI.html[URI, window=\_blank] for the request, as received by the web container.

+
The value of this field is read-only.

`"remainingUri"`: string::
The portion of the request URI that is remaining to be matched.

`"uriTemplateVariables"`: map::
An unmodifiable Map where the keys and values are strings. The map contains the parsed URI template variables keyed on the URI template variable name.

--
