== Logging Framework

ifdef::env-site[]
anchor:logging-conf[]
endif::env-site[]

OpenIG writes application logs through SLF4J. The WAR distribution uses Logback.

On startup, Logback can load a configuration from a local file specified by the JVM property `logback.configurationFile` or from its standard classpath locations. OpenIG keeps the preloaded configuration when its main configuration URL points to an existing local file. Otherwise OpenIG loads a readable `config/logback.xml` under the OpenIG base directory and falls back to the bundled `logback.xml`. In this branch, OpenIG sets `openig.base` in the Logback context.

OpenIG determines the base directory from the JVM property `openig.base`, then the `OPENIG_BASE` environment variable, then the xref:../gateway-guide/chap-install.adoc#install[platform default].

The bundled configuration writes `INFO` and higher messages to standard output and to rolling files under `+${openig.base}/logs+`. It uses the MDC field `routeId` to select `route-<routeId>.log`, with `system` as the fallback when no route ID is present. Each route ID, including `system`, has its own rolling appender. It rolls files daily and at `100 MB`, and keeps up to 30 days of history within a `3 GB` archive limit per appender.

Configure the logger `org.forgerock.openig.filter.LogAttachedExceptionFilter` at level `OFF` to suppress logs of exceptions attached to responses. The bundled configuration inherits the root level for this logger.

The following `logback.xml` writes application logs to standard output and enables `DEBUG` messages for capture decorators.

[source,xml]
----
<configuration>
  <appender name="STDOUT" class="ch.qos.logback.core.ConsoleAppender">
    <encoder>
      <pattern>%d %-5level %logger - %msg%n</pattern>
    </encoder>
  </appender>
  <logger name="org.forgerock.openig.decoration.capture.CaptureDecorator" level="DEBUG"/>
  <root level="INFO">
    <appender-ref ref="STDOUT"/>
  </root>
</configuration>
----

Use xref:audit-conf.adoc#AuditService[AuditService] to configure route access audit events and their destinations.

[#ConsoleLogSink]
=== Migrating from ConsoleLogSink

Configure a Logback `ConsoleAppender` for console output.

[#FileLogSink]
=== Migrating from FileLogSink

Configure a Logback `FileAppender` or `RollingFileAppender` to write logs to disk.

[#Slf4jLogSink]
=== Migrating from Slf4jLogSink

OpenIG already logs through SLF4J. Configure loggers and destinations in Logback and remove the legacy `logSink` configuration from `config.json` and heap objects.
