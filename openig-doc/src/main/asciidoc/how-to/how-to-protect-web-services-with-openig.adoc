[[how-to-protect-web-services-with-openig]]
== How to Protect Web Services with OpenIG
:imagesdir: ../

[[how-to-protect-web-services-with-openig-introduction]]
=== Introduction

Securing web services is critical part of production environment to prevent compromising application from attacks. In microservice architecture, there is no need to implement security for each microservice. Each microservice should be responsible for its atomic functionality. To protect services you need to use an API Gateway application. Consider how to protect simple web service with Open Identity Gateway (OpenIG) in the following article.

Source code for this article is located here: https://github.com/maximthomas/openig-protect-ws/

[[how-to-protect-web-services-with-openig-sample-service]]
=== Sample Service

Consider service application with 2 endpoints http://localhost:8080/ - public http://localhost:8080/secure - private, so only authenticated users should have access to it. This service implemented with https://spring.io/projects/spring-boot[Spring Boot:]

[source,java]
----
package org.openidentityplatform.sampleservice;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

import javax.servlet.http.HttpServletRequest;
import java.util.Collections;
import java.util.Map;

@SpringBootApplication
public class SampleServiceApplication {
    public static void main(String[] args) {
        SpringApplication.run(SampleServiceApplication.class, args);
    }

    @RestController
    public class IndexController {
        @RequestMapping("/")
        public Map<String, String> index() {
            return Collections.singletonMap("hello", "world");
        }

        @RequestMapping("/secure")
        public Map<String, String> secure(HttpServletRequest request) {
            return Collections.singletonMap("hello", request.getHeader("X-Auth-Username"));
        }
    }
}
----

==== HTTP Methods Restriction

We will restrict HTTP methods, leave only GET and POST methods allowed. To do that add `SwitchFilter` to `10-api.json`:

[source,json]

  "monitor": true,
  "timer": true,
  "handler": {
    "type": "Chain",
    "config": {
      "filters": [
        {
          "type": "SwitchFilter",
          "config": {
            "onRequest": [
              {
                "condition": "${request.method != 'POST' and request.method != 'GET'}",
                "handler": {
                  "type": "StaticResponseHandler",
                  "config": {
                    "status": 405,
                    "reason": "Method not allowed",
                    "headers": {
                      "Content-Type": [
                        "application/json"
                      ]
                    },
                    "entity": "{ \"error\": \"Method not allowed\"}"
                  }
                }

[[how-to-protect-web-services-with-openig-validate-accept-request-header-and-content-type-response-header]]
==== Validate Accept Request Header and Content-Type Response Header

Check whether the response media type is acceptable to the client. An absent `Accept` header allows any media type; lists, wildcards and quality values need more than an exact string comparison. The most specific matching range takes precedence, including a `q=0` exclusion.

Add a `ScriptableFilter` before the existing `SwitchFilter` in the route's `filters` array in `10-api.json`:

[source,json]
----
...
"filters": [
  {
    "type": "ScriptableFilter",
    "config": {
      "type": "application/x-groovy",
      "file": "accept.groovy"
    }
  },
  ...
]
...
----

Create `/openig-config/scripts/groovy/accept.groovy`. The script uses the Apache HTTP header parser and Guava media-type parser already available in OpenIG, including their handling of quoted parameters. It checks all `Accept` field values, ignores malformed ranges and leaves responses without a parseable `Content-Type` unchanged. It does not select or convert the upstream representation; if no matching range has a positive quality, it replaces the response with 406.

[source#how-to-protect-web-services-with-openig-accept-script,groovy]
----
import com.google.common.net.MediaType
import org.apache.http.message.BasicHeaderValueParser
import org.forgerock.http.header.ContentTypeHeader
import org.forgerock.http.header.MalformedHeaderException
import org.forgerock.http.protocol.Response
import org.forgerock.http.protocol.Status
import org.forgerock.util.Function

boolean accepts(List<String> fields, ContentTypeHeader contentType) {
    if (fields == null || contentType == null) {
        return true
    }
    def representation
    try {
        if (contentType.type == null) {
            throw new IllegalArgumentException('Missing media type')
        }
        representation = MediaType.parse(contentType.type)
        if (contentType.charset != null) {
            representation = representation.withCharset(contentType.charset)
        }
        if (contentType.boundary != null) {
            representation = representation.withParameter(
                    'boundary', contentType.boundary)
        }
        for (parameter in contentType.additionalParameters) {
            if (parameter.value == null) {
                throw new IllegalArgumentException('Missing parameter value')
            }
            representation = representation.withParameter(
                    parameter.key, parameter.value)
        }
    } catch (IllegalArgumentException ignored) {
        // An unparseable media type or an unknown charset is left unchanged.
        return true
    }
    def qualityPattern = ~/(?:0(?:\.[0-9]{0,3})?|1(?:\.0{0,3})?)/
    int bestType = -1
    int bestParameters = -1
    BigDecimal bestQuality = BigDecimal.ZERO
    for (element in BasicHeaderValueParser.parseElements(fields.join(','), null)) {
        try {
            if (element.value != null) {
                throw new IllegalArgumentException('Invalid media range')
            }
            def range = MediaType.parse(element.name)
            BigDecimal quality = BigDecimal.ONE
            boolean qualitySeen = false
            for (parameter in element.parameters) {
                if (parameter.value == null) {
                    throw new IllegalArgumentException('Missing parameter value')
                }
                if (parameter.name.equalsIgnoreCase('q')) {
                    if (qualitySeen || !(parameter.value ==~ qualityPattern)) {
                        throw new IllegalArgumentException('Invalid quality')
                    }
                    qualitySeen = true
                    quality = new BigDecimal(parameter.value)
                } else {
                    range = range.withParameter(parameter.name, parameter.value)
                }
            }
            if (!representation.is(range)) {
                continue
            }
            int type = range.type() == '*' ? 0 : (range.subtype() == '*' ? 1 : 2)
            int parameters = range.parameters().size()
            if (type > bestType ||
                    (type == bestType && parameters > bestParameters)) {
                bestType = type
                bestParameters = parameters
                bestQuality = quality
            } else if (type == bestType && parameters == bestParameters) {
                bestQuality = bestQuality.max(quality)
            }
        } catch (IllegalArgumentException ignored) {
            // A malformed range does not make a representation acceptable.
        }
    }
    return bestQuality > 0
}

return next.handle(context, request).then({ response ->
    ContentTypeHeader contentType
    try {
        contentType = response.headers.get(ContentTypeHeader)
    } catch (MalformedHeaderException ignored) {
        return response
    }
    if (accepts(request.headers['Accept']?.values, contentType)) {
        return response
    }
    response.close()
    def rejected = new Response(Status.NOT_ACCEPTABLE)
    rejected.headers['Content-Type'] = 'application/json'
    rejected.setEntity('{"error":"Not Acceptable"}')
    return rejected
} as Function)
----

[[how-to-protect-web-services-with-openig-add-response-security-headers-x-frame-options-and-x-content-type-options]]
==== Add Response Security Headers X-Frame-Options and X-Content-Type-Options

OpenIG should return `X-Frame-Options: deny` and `X-Content-Type-Options: nosniff` headers to client to prevent XSS and drag'n drop clickjacking attacks in older browsers. To do that, add `HeaderFilter` to filter chain after `SwitchFilter`:

`10-api.json`:

[source,json]
----
       {
          "type": "HeaderFilter",
          "comment": "Add security headers to response",
          "config": {
            "messageType": "response",
            "add": {
              "X-Frame-Options": [ "deny" ],
              "X-Content-Type-Options": [ "nosniff" ]
            }
          }
        }
----

[[how-to-protect-web-services-with-openig-authentication-check]]
==== Authentication Check

If you need to protect services from unauthenticated access, there is no need to implement access control on each service. You can check access to the service with OpenIG, and if access has been granted, enrich request with the headers containing identity information. For example, authentication service returns to the client signed https://en.wikipedia.org/wiki/JSON_Web_Token[JSON Web Token] (JWT) and client use this JWT to authenticate in service. There is a public key on OpenIG and OpenIG verifies the JWT signature and enriches the request with identity headers.

Generate keys:

private:

[listing]
----
$ openssl genrsa -out private_key.pem 4096
----

and public:

[listing]
----
$ openssl rsa -pubout -in private_key.pem -out public_key.pem
----

Example keys are in source folder: https://github.com/maximthomas/openig-protect-ws/tree/master/openig-config/keys

[[how-to-protect-web-services-with-openig-jwt-validation]]
==== JWT Validation

To validate JWT for `/secure` URL lets add to main filter chain another `SwitchFilter`, which will toggle `Chain` handler if target url matches `/secure`. Add to `Chain` handler `ScriptableFilter` with `jwt.groovy` script, which will validate JWT and enrich request with authentication data headers.

`10-api.json`:

[source,json]
----
...
        {
          "type": "SwitchFilter",
          "config": {
            "onRequest": [
              {
                "condition": "${matches(request.uri.path, '^/secure')}",
                "handler": {
                  "type": "Chain",
                  "config": {
                    "filters": [
                      {
                        "type": "ScriptableFilter",
                        "config": {
                          "type": "application/x-groovy",
                          "file": "jwt.groovy",
                          "args": {
                            "iss": {
                              "sample-service": "${read('/usr/local/openig-config/keys/public_key.pem')}"
                            }
                          }
                        }
                      }
                    ],
                    "handler": "EndpointHandler"
                  }
                }
              }
            ]
          }
        }
...
----

Add `jwt.groovy` file to `/openig-config/scripts/groovy/`. This script verifies JWT signature with the public key and if signature verified, checks JWT expiration. If JWT is valid, script adds header with name JWT claim to the request. Otherwise, script returns 401 HTTP status.

`jwt.groovy`:

[source,Groovy]
----
import java.security.KeyFactory
import org.forgerock.json.jose.builders.JwtBuilderFactory
import org.forgerock.json.jose.jws.SignedJwt
import org.forgerock.json.jose.jws.SigningManager
import org.forgerock.http.protocol.Status
import java.security.spec.X509EncodedKeySpec

//extract jwt from request header
def jwt = request.headers['Authorization']?.firstValue

if (jwt!=null && jwt.startsWith("Bearer eyJ")) {
    jwt=jwt.replace("Bearer ", "")

    try {
        //parse jwt
        def sjwt=new JwtBuilderFactory().reconstruct(jwt, SignedJwt.class)

        //verify jwt signature
        if (!sjwt.verify(new SigningManager().newRsaSigningHandler(getKey(sjwt.getClaimsSet())))) {
            throw new Exception("invalid signature")
        }

        //check jwt expiration
        if ((sjwt.getClaimsSet().getExpirationTime()!=null && sjwt.getClaimsSet().getExpirationTime().before(new Date()))) {
            throw new Exception("signature expired "+sjwt.getClaimsSet().getExpirationTime())
        }

        //add name from JWT claim to header
        request.headers.put('X-Auth-Username', sjwt.getClaimsSet().getClaim("name"))

        return next.handle(new org.forgerock.openig.openam.StsContext(context, jwt), request)
    } catch(Exception e) {
        e.printStackTrace();
        return getErrorResponse(Status.UNAUTHORIZED, e.getMessage())
    }
} else {
    //returns 401 status if JWT not present in request
    return getErrorResponse(Status.UNAUTHORIZED, "Not Authenticated")
}

return next.handle(context, request)


def getErrorResponse(status, message) {
    def response = new Response()
    response.status = status
    response.headers['Content-Type'] = "application/json"
    response.setEntity(groovy.json.JsonOutput.toJson([error: message]))
    return response
}

def getKey(claims) {
    def pem=iss[claims.getIssuer()]
    if (pem != null) {
        def pemReplaced = pem.replaceFirst("(?m)(?s)^---*BEGIN.*---*\$(.*)^---*END.*---*\$.*", "\$1")
        byte[] encoded = Base64.getMimeDecoder().decode(pemReplaced)
        def kf = KeyFactory.getInstance("RSA")
        def pubKey = kf.generatePublic(new X509EncodedKeySpec(encoded))
        println 'got pub key' + pubKey
        return pubKey
    }

    throw new Exception('Unknown issuer')
}

[[how-to-protect-web-services-with-openig-authorization-check]]
==== Authorization Check

Let's configure OpenIG so it authorizes access only to users with the `manager` role. The role will be taken from the `role` JWT claim . If the JWT `role` claim does not exist or is different from `manager`, OpenIG will return 403 Forbidden HTTP status.

Let's add the `allowedRole` parameter to the `ScriptableFilter` filter in the route so that we can set the allowed role in the route without changing the script.

[source,json]
----
...
{
  "type": "ScriptableFilter",
  "config": {
    "type": "application/x-groovy",
    "file": "jwt.groovy",
    "args": {
      "iss": {
        "sample-service": "${read('/usr/local/openig-config/keys/public_key.pem')}"
      },
      "allowedRole": "manager"
    }
  }
}
...
----

Let's add a role check to `jwt.groovy` after the JWT validation:

[source,Groovy]
----
//check jwt expiration
if ((sjwt.getClaimsSet().getExpirationTime()!=null && sjwt.getClaimsSet().getExpirationTime().before(new Date()))) {
    throw new Exception("signature expired "+sjwt.getClaimsSet().getExpirationTime())
}

//check role
 if (!sjwt.getClaimsSet().keys().contains("role")
    || !allowedRole.equals(sjwt.getClaimsSet().getClaim("role", String.class))) {
     return getErrorResponse(Status.FORBIDDEN, "Forbidden")
}
----
