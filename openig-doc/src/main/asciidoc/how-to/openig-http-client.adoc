[[openig-http-client]]
== OpenIG HTTP Client
:imagesdir: ../

Use the built-in Common HTTP Framework (CHF) client from an OpenIG script to call another HTTP service. Both examples call OpenAM's session logout endpoint from a filter on a logout route.

[[openig-http-client-background]]
=== Background

OpenIG exposes a CHF `Client` as the `http` script binding. `http.send(context, request)` returns a promise of a CHF response. Responses received by the script must be closed if the script consumes them. A response passed back to the caller remains open for the platform to send.

[[openig-http-client-migrated-example-script]]
==== Blocking example

Save this script as `logout-blocking.groovy` under `$OPENIG_BASE/scripts/groovy/`. Supply `openamUrl` as a script argument, for example `https://openam.example.org/openam` without a trailing slash. Use the script only on an explicit logout route. Configure the client handler's connection and read timeouts to bound HTTP operations.

[source#http-client-blocking-script,groovy]
----
import org.forgerock.http.protocol.Request

def token = request.cookies['iPlanetDirectoryPro']?.getAt(0)?.value
if (!token) {
    return next.handle(context, request)
}

def logout = new Request()
    .setMethod('POST')
    .setUri(openamUrl + '/json/sessions/?_action=logout')
logout.headers.put('iPlanetDirectoryPro', token)

def response = http.send(context, logout).getOrThrow()
try {
    if (response.status.successful) {
        logger.info('OpenAM logout result: {}', response.entity.json.result)
    } else {
        logger.warn('OpenAM logout returned HTTP {}', response.status.code)
    }
} catch (IOException ignored) {
    logger.warn('OpenAM logout response could not be read')
} finally {
    response.close()
}

return next.handle(context, request)
----

`getOrThrow()` waits for the HTTP response on the current thread. The script reads the logout result for a successful response and closes the response in `finally`, including when reading the JSON fails. It then continues the original request through the chain.

[[openig-http-client-migrate-to-chf-asynchronous-apis]]
=== Using the asynchronous CHF API

With the asynchronous API, the callback processes the response when it arrives. The script returns the chained promise immediately and the HTTP client timeouts still apply.

[[openig-http-client-migrated-example-script-1]]
==== Asynchronous example

Save this version as `logout-async.groovy` in the same scripts directory. It uses the same `openamUrl` argument.

[source#http-client-async-script,groovy]
----
import org.forgerock.http.protocol.Request
import org.forgerock.util.AsyncFunction

def token = request.cookies['iPlanetDirectoryPro']?.getAt(0)?.value
if (!token) {
    return next.handle(context, request)
}

def logout = new Request()
    .setMethod('POST')
    .setUri(openamUrl + '/json/sessions/?_action=logout')
logout.headers.put('iPlanetDirectoryPro', token)

return http.send(context, logout).thenAsync({ response ->
    try {
        if (response.status.successful) {
            logger.info('OpenAM logout result: {}', response.entity.json.result)
        } else {
            logger.warn('OpenAM logout returned HTTP {}', response.status.code)
        }
    } catch (IOException ignored) {
        logger.warn('OpenAM logout response could not be read')
    } finally {
        response.close()
    }
    return next.handle(context, request)
} as AsyncFunction)
----

To use the asynchronous version, place this filter on the logout route before its handler and set the OpenAM URL.

[source,json]
----
{
  "type": "ScriptableFilter",
  "config": {
    "type": "application/x-groovy",
    "file": "logout-async.groovy",
    "args": {
      "openamUrl": "https://openam.example.org/openam"
    }
  }
}
----

[[openig-http-client-groovy-specific-points]]
==== Groovy specific points

The callback passed to `thenAsync` returns the promise from `next.handle(context, request)`. The explicit `as AsyncFunction` cast adapts the Groovy closure to the Promise API.

[[openig-http-client-further-information-on-the-promise-object]]
=== Further information on the Promise object

Use `then` to transform a promise result, `thenAsync` when the callback returns another promise, and `thenOnResult` for a notification that preserves the result. If a callback consumes an HTTP response, close it there before continuing with a different result.
