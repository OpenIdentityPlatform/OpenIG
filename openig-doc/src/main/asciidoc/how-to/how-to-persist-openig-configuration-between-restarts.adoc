[[how-to-persist-openig-configuration-between-restarts]]
== How to Persist OpenIG Configuration Between Restarts
:imagesdir: ../

OpenIG stores its configuration data in `/usr/local/openig-config` directory. If you need to customize OpenIG configuration and need OpenIG Docker container to load it, mount your local folder to the OpenIG docker image

With `docker-compose.yaml` file

[source,yaml]
----
services:
  openig:
    image: openidentityplatform/openig:latest
    volumes:
      - ./openig-config:/usr/local/openig-config/config
    ports:
      - "8080:8080"
----

With `docker run` command:

[listing]
----
docker run -h openig-01.domain.com \
    -p 8080:8080 \
    --name openig-01 \
    -v ./openig-config:/usr/local/openig-config/config \
    openidentityplatform/openig
----
