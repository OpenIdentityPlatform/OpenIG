== How to Persist OpenIG Configuration Between Restarts
:imagesdir: ../

The OpenIG image sets `OPENIG_BASE=/var/openig`. Mount a host directory at `/var/openig/config` to keep configuration files when the container is replaced. Create `openig-config` next to the Compose file and put `admin.json`, `config.json` and the `routes/` directory directly in it. The container user (UID 1001) needs read access.

Scripts live under `/var/openig/scripts`. To persist scripts and configuration together, mount a host directory at `/var/openig` with separate `config/` and `scripts/` subdirectories.

Use this `compose.yaml` file.

[source,yaml]
----
services:
  openig:
    image: openidentityplatform/openig:latest
    volumes:
      - ./openig-config:/var/openig/config:ro
    ports:
      - "8080:8080"
----

The equivalent `docker run` command uses an absolute host path.

[listing]
----
docker run -h openig-01.domain.com \
    -p 8080:8080 \
    --name openig-01 \
    -v "$PWD/openig-config":/var/openig/config:ro \
    openidentityplatform/openig
----
